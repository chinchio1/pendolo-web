Seismic Noise Dumping Simulation

A web tool to model seismic noise filters used in ground-based laser interferometers.

This code models seismic noise filtering in ground-based laser interferometers. It takes as input a set of damped sinusoidal functions, representing an approximation of ground vibrations parallel to the laser’s propagation direction. The output is the residual noise after suppression by a multistage pendulum system. Users can adjust physical parameters and noise components to explore how such pendulum systems mitigate seismic disturbances. The current implementation employs a simplified double pendulum with equal masses and lengths. For further details on the structure of the simulation and on the theoretical and observational aspects of gravitational waves, see my second-year bachelor term paper: Introduction to Gravitational Waves and Gravitational Waves Observation.
